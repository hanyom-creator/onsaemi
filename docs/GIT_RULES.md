# 온새미 Git 규칙

- WBS 1.3.2 / 확정일 2026-09-21

## 브랜치

작업 브랜치 → `dev` → `main`

- `main`: 세션 종료 판정을 통과한 상태만 병합
- `dev`: 작업 브랜치를 모아 통합 확인
- 작업 브랜치 이름: `유형/작업내용-WBS번호`
  - 예: `feat/fastapi-routing-ngrok-3.1.1`

## 커밋 메시지

`[WBS번호] 유형: 내용`

| 유형 | 용도 |
|---|---|
| feat | 기능 추가 |
| fix | 버그 수정 |
| docs | 설계 문서, 세션 로그 |
| exp | 실험 설정, 측정 결과 |
| refactor | 동작 변화 없는 구조 변경 |
| chore | 설정, 의존성 |

## 태그

| 태그 | 시점 |
|---|---|
| `v0.<세션>.0` | 세션 종료 판정 충족 (예: S1 → `v0.1.0`) |
| `v0.<세션>.0-partial` | 판정 미충족으로 세션 종료 |
| `v0.<세션>.<n>` | main 긴급 수정 |
| `paper-submit` `mid-demo` `exp-build` `final-build` | 마일스톤, 버전 태그와 같은 커밋에 추가 |
| `v1.0.0` | 최종 빌드 |

- 태그는 주석 태그(`git tag -a`)로 달고 메시지에 판정 결과를 적는다.
- 실행 파일(APK)은 커밋하지 않고 해당 태그의 GitHub 릴리스에 첨부한다.

## 폴더

`server/` `android/` `tools/` `docs/`, 명세는 루트 `SPEC.md`

## 커밋 제외

- 키 파일(`*.json`)은 커밋하지 않는다. 올려야 하는 JSON은 `git add -f`로 추가한다.
- 음성 파일(`*.wav`)은 커밋하지 않는다.
