# 위험 신호 가중치 표 v1.0

- WBS 1.2.1 / 확정일 2026-09-21
- 초기 설정값이며 S8 실측 데이터로 보정한다 (6.5.1). 논문 5장 수치는 보정 전 실험용 빌드 기준으로 적는다.

## 가중치

| 태그 | 신호 | 가중치 | 탐지 | 예시 |
|---|---|---|---|---|
| 기관사칭 | 수사기관·금융기관 사칭 | +25 | LLM | "서울중앙지검 수사관입니다" |
| 이체요구 | 금전 이체·자산 이동 요구 | +25 | LLM | "안전계좌로 옮기셔야 합니다" |
| 원격제어유도 | 앱 설치·URL 접속·원격제어 | +30 | LLM | "보내드린 링크로 설치하세요" |
| 고립요구 | 주변 상의 차단 | +20 | LLM | "가족에게 말하지 마세요" |
| 개인정보요구 | 개인정보·금융정보 요구 | +15 | LLM | "주민번호 뒷자리 불러주세요" |
| 긴급성압박 | 시간 압박 | +15 | LLM | "지금 안 하시면 동결됩니다" |
| 수취계좌제시 | 사기범 측 계좌번호 발화 | +15 | 정규식 | "302-xxxx-xxxx로 보내세요" |
| 탐침후재압박 | Lv2 검증 질문에 회피·압박 강화 | +30 | LLM | "확인할 시간 없어요" |

- +15 신호 세 개만으로는 최대 45점이라 스크립트 기준(65점)을 넘지 못한다. 핵심 신호가 하나 이상 있어야 넘는다.

## 누적 규칙

1. 처음 나온 신호는 전체 점수를 더한다.
2. 같은 신호가 마지막 가산 시점부터 30초 안에 다시 나오면 무시한다.
3. 30초가 지난 뒤 다시 나오면 직전 가산값의 절반을 더한다 (소수점 버림).
   - 예: 기관사칭 25 → 12 → 6 → 3 → 1 → 0
4. 탐침후재압박은 1~3번 규칙을 적용하지 않고, 탐침 1회당 1회 가산한다.
5. 한 청크에서 여러 신호가 나오면 합산한다.
6. 점수는 100을 넘지 않는다.
7. 65점 미만이면 스크립트를 출력하지 않는다.

## 점수 외 강제 승급

사용자가 카드번호·주민등록번호·CVC·인증번호를 말하면 점수와 무관하게 즉시 Lv4로 올린다.
