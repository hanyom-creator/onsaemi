## 막힌 것
- uvicorn.exe가 PC 보안 정책(Device Guard)에 차단됨 → `python -m uvicorn`으로 실행
- 서비스 계정 키 파일명이 설정(gcp-key.json)과 달라 서버 기동 실패 → 파일명 변경
- 테스트 음성 생성 스크립트(.ps1)가 BOM 없는 UTF-8이라 PowerShell 5.1이 CP949로 읽어 한글 문장이 깨짐
  → 음성 길이 32.7초(정상 약 16초), 전사 결과가 문장과 무관
  → .ps1을 UTF-8 BOM으로 저장, 문장은 별도 텍스트 파일에서 읽도록 변경
